# Tree-sitter tag queries

These `*-tags.scm` files are copied from Aider (https://github.com/Aider-AI/aider,
Apache-2.0), `aider/queries/tree-sitter-language-pack` and
`aider/queries/tree-sitter-languages`, which adapt the tag queries published
by each language's tree-sitter grammar repository (see
https://github.com/Goldziher/tree-sitter-language-pack for the per-grammar
licenses, mostly MIT). Where both Aider folders had a file, the
language-pack version was kept.
